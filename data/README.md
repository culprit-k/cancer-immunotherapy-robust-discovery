# Data directory

Do not commit raw datasets here by default.

## Policy
- Obtain data only from the original source or an authorised repository.
- Check licence, terms of use, and any access restrictions before downloading or redistributing.
- Record accession/DOI, version, retrieval date, checksum, and citation in the data audit.
- Keep patient identifiers and restricted or identifiable information out of this repository.
- Use this directory for small synthetic examples or permitted derived files only when appropriate.
- Keep large raw files and restricted datasets outside Git history.

## Candidate dataset
The Morpheus melanoma spatial-proteomics dataset (DOI: https://doi.org/10.5281/zenodo.5994135) is a candidate for feasibility testing. It has not yet been audited locally in this project.
